Evaluation Essay Studio

A practice room for the Evaluation Essay. Pick a cultural or literary monster, set clear criteria, and draft a judgment that uses secondary research. Guides live on the Essays overview Doc; Tools links open practice helpers. Keep AI at Level 2 (support, not composition).

Purpose

Evaluate one cultural or literary monster using explicit criteria. Judgment + criteria + evidence; not plot summary. Do not use Stranger Things for this essay. Course Text length: 2 to 3 pages (not including Works Cited), minimum 750 words, maximum 1,000 words.

Reading and skills cues

Readings. Possible primary angles include Jackson "The Lottery," Shelley Frankenstein, Gilman "The Yellow Wallpaper," King "The Boogeyman," La Llorona / El Cucuy / Donkey Lady / Chupacabra, King "Why We Crave Horror," Cohen "Monster Culture," and NPR Code Switch. Do not use Stranger Things for this essay.

Skills. Criteria thesis, judgment, and intro secondary research.

Assignment overview
  • Evaluate one cultural or literary monster using explicit criteria (effectiveness, cultural function, or impact).
  • Judgment + criteria + evidence; not plot summary. Do not use Stranger Things for this essay.
  • Length (Course Text): 2 to 3 pages (not including Works Cited); minimum 750 words; maximum 1,000 words. At least 2 credible sources.
Suggested readings (pasteable titles)
  • Literary: Shirley Jackson, “The Lottery”; Mary Shelley, Frankenstein; Charlotte Perkins Gilman, “The Yellow Wallpaper”; Stephen King, “The Boogeyman.”
  • Folklore / cultural: La Llorona; El Cucuy / El Cuco; Donkey Lady; Chupacabra (“The Chupacabra Takes Texas,” Texas Observer).
  • Rhetorical / nonfiction: Stephen King, “Why We Crave Horror Movies”; Jeffrey Jerome Cohen, “Monster Culture (Seven Theses)”; NPR Code Switch, “The Real Reason We See Monsters Everywhere.”
