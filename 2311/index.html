Technical and business writing practice room. Open a project studio for Purpose and how to practice. Drive assignment sheets are thin for this course so Purposes below come from the Canvas course notes.

Purpose

Each project has its own Purpose on its block or studio page. Open the project you are practicing, read that purpose, then use Practice path and Tools.

How to use this room

How this room is organized

1ResourcesCourse map, syllabus pointers, and project pack notes. 2Practice pathStart to practice steps for the project you are on. 3ToolsThesis, outline, citation, source log, peer checklist, keywords. 4ProjectsOne block per project.

Majors

Majors

Project 1 · studioAudience AnalysisCharacterize a specific audience for a technical document (demographics, expertise, purpose, attitudes, design preferences), then present the analysis. Use the Audience Profile sheet as you draft. Project 2 · studioResearch ProposalDraft a 5 to 7 page APA research proposal for a problem or need in your field: purpose, summary, introduction, proposed program, qualifications, budget, and appendixes. Project 3 · studioRecommendation ReportBuild on your proposal into a recommendation report: identify the problem or opportunity, evaluate options against criteria, and recommend a course of action with research depth and clarity. Project 4 · studioJob ApplicationAssemble a job application package: professional resume, tailored cover letter, employer expectations research, LinkedIn brand work, then place the package on your portfolio site. Final · studioDigital PortfolioCurate a digital portfolio website of your technical writing from the course, include the job application packet, and write an 800 to 1,000 word progress report on your development.
