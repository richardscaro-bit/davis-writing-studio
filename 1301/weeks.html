Practice path

Use this path for whichever essay you are practicing. Open that essay’s block on Home, then work the steps with Tools and Resources. Purpose for each essay lives on its own room (or Tools block). This page is the start-to-practice map only.

Start practicing

Pick the essay you are on, read that essay’s Purpose, then move through brainstorm, thesis and outline, draft, then peer review and polish. Tools and Resources support every essay; dedicated studios have their own workspace when one exists.

Step 1
Focus · pick essay

Pick your essay

Jump to Essays on Home and open the room for the essay you are practicing. If that essay still points to Tools (Narrative Quest, Classical Argument, Final Reflection), start there until a dedicated studio is ready.

Essays on Home Tools
Step 2
Focus · Purpose

Read the Purpose

Know the task for that essay before you draft. Each essay block and studio states its Purpose: length, genre, and what the writing should do. Read it once, then keep it in view while you practice.

Essay Purposes Resources
Step 3
Focus · brainstorm

Brainstorm / gather

Collect questions, angles, and evidence for the essay you chose. Use Tools (thesis helper later) and Resources (library and Scholar help, keyword generator, research tips) so you have material before you lock a thesis.

Keyword generator Resources All tools
Step 4
Focus · thesis + outline

Thesis + outline

Shape a working thesis, then a short outline. Practice with the thesis helper and outline helper; carry what you keep into the essay’s studio when it has one.

Thesis / claim tool Outline helper
Step 5
Focus · draft + sources

Draft + sources

Build a working draft and track sources as the essay asks for them. Use the source log and MLA practice tools; draft in the essay’s studio when that room has a workspace.

Source log MLA practice Essay rooms
Step 6
Focus · peer + polish

Peer + polish

Rehearse one peer review, check AI Level 2 (support, not composition), and run a final checklist if the studio has one. Polish citations and reader feedback before you call the practice draft done.
